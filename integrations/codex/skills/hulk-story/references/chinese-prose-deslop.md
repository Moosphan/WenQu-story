# 中文章节正文自然度规范 · prose-v1

用于生成正文、按意见返修和综合审稿。目标是让读者相信场景和人物，减少模板感；不判断作者身份，不承诺通过朱雀或其他检测器。章节标题另见 chapter-titles.md。

## 先守住故事，再改表达

优先遵守作者指定的文风、视角、世界规则和人物声线。去AI味不能改金额、数量、日期、亲属关系、物品归属、知情范围、能力代价或伏笔状态；保留冲突、关键行动、情绪积累和结尾的剧情功能。整段只是在重复说明且没有新功能时可以合并，不使用固定删减比例。只改变表达的修改不作为新正史事实入库。

原文自然就保留。不得全篇替换同义词、统一改短句、强制口语化或改成第一人称。修仙人物不应突然说现代网络黑话；寡言、文雅或刻薄的角色也不必说同一种“接地气”语言。

## 句式参考字典

写作与审稿时参考[常见模板句式字典 phrase-v1](ai-phrase-dictionary.md)。它覆盖总结金句、越界旁白、动作情绪套件和段落节奏，共36类。先核对语境与重复的功能损失，再决定修改；单次命中不判AI、不硬拦截，作者有意的句式与角色口头禅可以保留。具体问题可在现有 dimension 中引用条目ID，不扩展任务合约。

## 重点识别与处理

| 问题 | 判断依据 | 修改方向 |
|---|---|---|
| 越过感知范围 | 限知主体不可能知道他人内心、远处变化或未来结局 | 改为可见行动、听闻或明确推测；必要视角切换遵循已有约定，不一律禁止全知叙述 |
| 情绪被讲解代替 | 行动之后再解释一遍“这意味着成长、信任、希望” | 删除重复结论；保留真正推动下一选择的心理活动。可以直述心情，不强制每次用手抖、攥拳、咬牙替换 |
| 人人同声 | 不同身份的人都说完整道理、对仗金句，互相配合讲设定 | 结合当下目的安排回应：躲避、讨价、误解、停顿。对白需要推进关系，不为增加碎句而断句 |
| 解释链重复 | 场景展示→旁白复述→人物总结→章末升华表达同一信息 | 留最有效的一处。交代必要因果不算AI味，删除后读者仍需理解为何这么做 |
| 过度整齐 | 连续段落都以动作起头、比喻居中、感悟结尾；每段长度相同 | 让事件速度和注意焦点决定长短。允许长句、连贯叙述与安静段落，不设置句长配额 |
| 空泛修辞 | 比喻或意象可移到任何人物、任何章节仍成立 | 换成已有场景中有功能的细节，或直接删去；不凭空加入气味、伤疤、经历凑真实感 |
| 动作套件 | 连续使用“眼底闪过”“唇角勾起”“深吸一口气”而没有新信息 | 只改重复、无功能的使用；某个词出现一次不是不合格，也不能机械换成另一套动作 |
| 中文翻译腔 | 代词堆积、冗长名词化、无必要的连接词造成阅读阻力 | 恢复自然主谓与指代；不能省成“他把它收起来”而丢失物品身份。中文标点与人名专名保持一致 |
| 机械章末 | 每章总结教训、宣布命运改变，或固定突发反转 | 以当前情节的行动、代价、余波或未解决问题结束；允许平静收束，不每章强塞悬念 |

## 原创示例：只在上下文成立时采用

**重复升华**

前：他把最后一枚铜钱推了过去。这不只是一笔买卖，更是一份承诺。他终于懂得，信任比灵石更加珍贵。

后：他把最后一枚铜钱推了过去。

若“承诺”此前没有通过交易条件成立，不能只删解释，须保留必要约定。例句展示删重复结论，不要求所有段落只剩一句。

**指代不能牺牲**

前：他看了看断剑，又摸到那半枚铜牌，把它收进衣袋。

后：他把半枚铜牌收进衣袋，断剑仍留在原处。

仅当原始事实确认收走的是铜牌、断剑未被移动时才能这样改；不确定则列为待核对，不替作者决定。

**表达不必全部动作化**

“他有些后悔。”可以自然有效。没有动作依据时，不必扩写成“他指节泛白，胸口像压了块巨石”。判断的是此句在上下文中的作用，不是是否命中词表。

## 写作与审稿如何执行

- 写作阶段：在当前调用内部检查本章重点场景与收尾；最多修正最明显的问题，再提交正文。不要为去AI味另起一条生成链。
- 综合审稿：沿用现有 verdict/issues/notes 合约、当前正文证据段落和总问题上限。局部套话/节奏偏好记 minor 或 medium，不单独触发返修；只有明显影响理解的整段重复、真正失控的视角等按现有 major 标准处理。
- 返修阶段：先处理本轮明确问题，优先定点修改；复查同一处是否修好，不更换审美标准。未涉及段落保留，避免全篇风格漂移。
- 最多三次综合审稿的规则不变；不得因检测分数或“仍不够像人”另开审稿循环。作者可接受有小问题的版本。
- 所有说明留在协议允许的审稿/返修字段，正文中不出现去AI味报告、检测分数、批注或创作解释。不得新增未定义 JSON 字段。

## 朱雀检测：可选外部观测，不是创作指挥棒

本项目未证明这套规范能降低朱雀分数。检测结果与读者感受分开记录，分数不作为放行门槛。不用故意错字、错标点、零宽字符、同形字、拼音替换、随机噪声、打乱因果来制造“人写感”，不伪造检测结果。

如作者要验证效果，先在本地完成少量同章前后对照，再由用户手动检测或另行明确接入；本规范不会自动上传未公开小说。保留完整章号/版本、文本哈希、检测时间、检测器可见版本、原始标签/分数以及实际改动。若页面不给版本，记“未提供”。不得把“疑似AI比例”解释成人工写作概率。

对照使用相同范围、相同文本长度处理方式，不靠截取低分片段掩盖全章结果。每个固定样本只做一次前后比较，必要重复单独记录；不根据同一检测器的反馈无限改写。读者同时看连贯性、声线、情绪、可读性和情节损失：分数下降但故事变差应判改写失败。

维护时记录规则版本与反例。新增规则必须说明具体阅读问题，不把单次检测结果总结成永远有效的禁词或句式公式。
