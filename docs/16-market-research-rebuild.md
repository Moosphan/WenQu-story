# 市场研究重构与调研

## 来源核查

- 番茄官方榜单：https://fanqienovel.com/rank/ 。公开 SSR 数据的书名、简介可能使用 PUA 字体编码；同一 bookId 的公开 `/page/{bookId}` 状态中可以取得正常中文。以 ID 关联补全，不执行网页脚本、不猜字、不复制小说章节。
- 榜单按分类排榜，不应称为全站总榜。官方链接使用 `性别_榜单类型_分类`，类型 2 是阅读榜，1 是新书榜。只读取当前页面条目，界面显示实际数量，不宣称已抓全榜。
- 起点官方：https://www.qidian.com/rank/ 。本轮桌面端实测返回 HTTP 202 验证页，移动端返回 403，尚未取得可验证榜单。提供重试与官方链接，不规避验证、不伪造数据。
- 参考调研：https://github.com/Beat1ngHeart/Novel-Ranking-Scanner 。对照其公开描述的多榜单、来源归档思路；未引入该仓库代码或字体映射。

## 实现

榜单与选题工作室分开。左侧选择具体分类榜，右侧搜索书籍、查看排名与简介、访问官方书页，再决定是否纳入选题。观察词是标题和简介中的词频，不能解释为增长趋势。现有选题草案仍使用规则模板，并非新实现的 AI 选题模型。

番茄详情补全最多四个并发请求，单次请求八秒超时；只读取单页最多二十本。公开 SSR 的 undefined 值被转为 null，字符串内容不变，不使用 eval。快照三十分钟内复用；更新失败保留上次成功内容并标为旧快照。源 URL 改变时不会复用旧榜单缓存。

## 验证边界

已以真实网络验证男/女频默认分类的阅读榜和新书榜，每页十本；女频详情出现 undefined 的故障已复现并修复。新增其他题材使用官方公开分类 ID，未逐个进行网络验收。起点未宣称接通，浏览器自动化服务不可用时不声称已完成视觉验收。
