# Edge TTS 章节听书

工作台的“写作”页现在提供章节听书播放器。它使用 Microsoft Edge TTS 生成 MP3，并按作品、章节、正文版本、音色、语速和正文内容缓存；同一版本重复播放不会重复生成，正文版本变化会自动得到新缓存。

安装可选依赖：

```bash
.venv/bin/pip install -e '.[tts]'
```

选择章节后点击播放，第一次会生成音频。播放器支持普通话音色、0.75×–1.5×语速、浏览器端音量和自动播放下一章。音量只影响本机播放，不会重新请求 Edge TTS；切换音色或语速会生成对应的新缓存。自动下一章只在本次播放会话结束时触发，不会启动写作、审稿或修改任务。

缓存位于 `books/tts-cache/`，属于派生文件，可以在停止服务后清理；不会写入 SQLite、正文、记忆或导出成稿。浏览器不会保存 API Key。Edge TTS 不可用时，写作流程仍然可以继续，播放器会显示安装依赖或网络错误。

该功能需要用户点击播放才会请求音频，避免页面加载时静默发送正文。发送到 Edge TTS 的内容是用户主动播放的当前章节正文；若作品包含敏感内容，请按自己的网络和服务合规要求使用。

## 下一章预加载

开启自动播放、正在播放且本章无未保存编辑时，进度达到 70% 会预生成下一章。按作品、章节版本、音色和语速识别缓存，只保留一个预加载请求；播放下一章时复用已完成或进行中的请求。失败不影响本章，到下一章时重新请求。换音色、换语速、切到其他章节或关闭自动播放会丢弃不适用的浏览器预加载；服务端已开始的合成可能继续完成并保留缓存。
