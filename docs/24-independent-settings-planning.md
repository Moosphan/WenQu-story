# 作品设置的独立规划

已有章纲的作品修改章节总数并保存后，后台立即启动独立规划。待应用的书名、篇幅和字数设置与正式配置隔离；全部批次通过校验后，设置与完整章纲在同一事务中发布。

- 关闭设置弹窗、切换页面不会中断后台规划。
- 规划期间不能启动章节写作或再次修改作品设置。
- 取消规划会丢弃待应用设置，保留原配置、章纲、正文、候选稿及已完结状态；迟到的模型结果不能提交。
- 模型失败、预算不足或服务重启后，可继续规划，复用已接受批次。预算调整沿用现有显式输入。
- 规划成功后恢复到暂停的章节任务，由用户单独继续写作，不自动生成或审查章节。
- 仅修改书名或每章字数不重做章纲；尚无章纲的新作品沿用初始化流程。

数据库版本为 11，新增 `settings_planning_jobs` 保存提案和原任务状态。部署前应备份 SQLite；回退旧程序需要同步恢复兼容的数据库备份。

旧版已开始的分批规划可通过 `adopt_planning` 接入独立流程，保留任务编号与版本对应的批次。接入时以当前正式配置为取消基线，不推测历史配置。
